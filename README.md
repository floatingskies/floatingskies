## whoami

I'm **Arik** — a self-taught designer and web programmer who started poking
computers at the age of **3** (Windows 7, class of 2011) and never really
pressed pause. My childhood was basically an endless power-up hunt: *what else
can this machine do?*

Today I mix my two favourite lives into a single cartridge: **design**, and
**technology that actually helps people**. I've been on desktop GNU/Linux since
**2023**, happily destroying my free time with theming ever since.

> *"It's not a bug, it's a secret level I haven't unlocked yet."*
